# Eskom Strategic Intelligence v1.0.0

## Scope

This release packages the source-controlled Eskom Strategic Intelligence case study as a reproducible Power BI and analytics engineering project built from governed public evidence.

## Included

- Editable Power BI Project using PBIP, PBIR and TMDL
- 5 report pages and 68 visuals
- 6 semantic-model tables and 3 one-way relationships
- 34 explicit DAX measures
- 40 governed source records
- SQLite analytical model with 5 semantic export views
- Python build orchestration
- 17 release-blocking data-quality checks
- 32 automated tests
- Ruff lint and format checks
- Deterministic double-build validation
- GitHub Actions Data Integrity CI
- Recorded Power BI Desktop runtime validation
- Completed five-page human visual and accessibility review

## Data governance corrections

The release protects the official FY2015-FY2026 municipal and metro arrears series. FY2024 total arrears are R74.4bn.

R55.3bn is kept separate as the approved legacy-debt scope of 71 Municipal Debt Relief Programme applications. It is not used as FY2024 total arrears.

The model also keeps the June 2026 R119.9bn in-year observation separate from year-end actuals and keeps the FY2031 R358bn Eskom management scenario outside reported actuals.

NERSA's FY2027/28 8.83% figure is represented as an average price/revenue path, not as the final tariff increase for every customer category.
